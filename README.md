# 🎾 Tennis Line Judge Web App

Esta es una aplicación web que usa la cámara de tu dispositivo para detectar si una bola de tenis ha caído dentro o fuera de la cancha, y además mide la velocidad de los golpes.

## 🚀 Cómo usar

1. Abre el archivo `index.html` en tu navegador (puedes subirlo a GitHub Pages o correrlo localmente).
2. Permite el acceso a la cámara.
3. Pulsa **"Iniciar"** para comenzar a detectar.
4. Usa **"Detener"** o **"Reiniciar"** cuando lo necesites.

## ⚙️ Funcionalidades

- Detección de pelotas por color.
- Indicación visual y textual de si la bola está dentro o fuera.
- Estimación de velocidad del golpe (en km/h).

## 📱 Compatible con

- Navegadores modernos (Chrome, Safari, Edge)
- Cámaras de teléfonos Android o iOS (usando navegador)

## 🛠️ Requisitos

- Cámara con acceso desde el navegador.
- Buenas condiciones de iluminación.
- Pelotas con colores detectables (como amarillo fluorescente).
